## 系统简介

这是一个基于Flask的DNS解析与IP地理位置查询系统，支持：

- ✅ 多DNS服务器批量查询
- ✅ IP地理位置信息展示（国家、城市）
- ✅ 查询历史记录
- ✅ 本地MMDB数据库优先查询
- ✅ 中文城市名称映射
- ✅ 自动日志管理与压缩

### 技术栈

- **后端**: Flask + dnspython + maxminddb
- **前端**: Vue 3 + Axios
- **数据库**: IPinfo MMDB + MaxMind GeoLite2
- **缓存**: TTLCache (10分钟)
- **并发**: ThreadPoolExecutor (20线程)

## 数据库配置

### 支持的数据库格式

系统支持多种MMDB数据库，按优先级查询：

1. **IPinfo MMDB** (推荐)
2. **MaxMind GeoLite2**
3. **其他兼容格式**

### 数据库获取

#### 方式一：IPinfo MMDB (精度高，免费版有限制)

1. 注册 IPinfo 账号: https://ipinfo.io/signup
2. 获取免费的 Lite MMDB: https://ipinfo.io/products/free-ip-database
3. 下载 `ipinfo_lite.mmdb`
4. 放置到: `server/db/ipinfo_lite.mmdb`

**特点**：
- ✅ 城市级精度
- ✅ 数据更新频繁
- ❌ 免费版有IP数量限制
- 📦 文件大小: ~37MB

#### 方式二：MaxMind GeoLite2 (覆盖率高，免费)

1. 注册 MaxMind 账号: https://www.maxmind.com/en/geolite2/signup
2. 生成 License Key
3. 下载 GeoLite2-City MMDB: https://www.maxmind.com/en/accounts/current/geoip/downloads
4. 解压到: `server/db/GeoLite2-City.mmdb`

**特点**：
- ✅ 覆盖率高 (95%+)
- ✅ 完全免费
- ✅ 每月更新
- 📦 文件大小: ~60MB

**自动下载脚本**（已集成）：
```python
import requests
import tarfile

LICENSE_KEY = "your_license_key"
DOWNLOAD_URL = f"https://download.maxmind.com/app/geoip_download?edition_id=GeoLite2-City&license_key={LICENSE_KEY}&suffix=tar.gz"

response = requests.get(DOWNLOAD_URL, stream=True)
with open("GeoLite2-City.tar.gz", "wb") as f:
    f.write(response.content)

with tarfile.open("GeoLite2-City.tar.gz", "r:gz") as tar:
    tar.extractall("db")
```

### 数据库放置位置

```
server/
├── db/
│   ├── ipinfo_lite.mmdb        # IPinfo数据库
│   └── GeoLite2-City.mmdb       # MaxMind数据库
```

### 查询优先级

```
缓存 (TTLCache 10min) 
  → IPinfo MMDB 
    → GeoLite2 MMDB 
      → IPinfo API (降级)
```

## 日志管理

### 日志系统特性

✅ **统一文件命名**: 所有日志写入 `log/app.log`  
✅ **自动轮转**: 每天午夜自动轮转  
✅ **自动压缩**: 轮转后自动gzip压缩 (节省73%空间)  
✅ **启动清理**: 每次启动自动清理空文件和归档旧日志  
✅ **归档管理**: 7天以上移至archive/，90天后自动删除  

### 日志结构

```
log/
├── app.log                      # 当前活跃日志
├── app.log.2026-01-25.gz        # 昨天的日志 (已压缩)
├── app.log.2026-01-24.gz        # 前天的日志 (已压缩)
└── archive/                     # 归档目录 (7天以上)
    ├── app.log.2026-01-18.gz
    └── app.log.2026-01-17.gz
```

### 日志保留策略

| 时间范围 | 存储位置 | 状态 |
|---------|---------|------|
| 当天 | `log/app.log` | 活跃写入 |
| 1-30天 | `log/app.log.YYYY-MM-DD.gz` | 压缩存档 |
| 30-90天 | `log/archive/app.log.YYYY-MM-DD.gz` | 长期归档 |
| 90天+ | - | 自动删除 |

## 故障排查

### 常见问题

#### 1. 数据为空（前端显示"X条记录"但无内容）

**原因**: 后端返回嵌套数组 `[[{...}], [{...}]]`

**解决**: 已修复 (使用 `extend` 替代 `append`)

**临时方案**: 前端会自动展平数组

#### 2. 请求超时（30秒超时错误）

**原因**: DNS解析和IP查询无超时控制

**解决**: 
- 前端超时: 30s → 90s
- DNS超时: 5s
- API超时: 5s
- 线程池: 5 → 20

#### 3. MMDB查询错误

**错误信息**:
```
ERROR - MMDB查询出错: The city method cannot be used with the ipinfo bundle_location_lite.mmdb database
```

**原因**: 使用了 `geoip2` 库读取IPinfo格式

**解决**: 改用 `maxminddb` 库直接读取

**正确用法**:
```python
import maxminddb

reader = maxminddb.open_database('db/ipinfo_lite.mmdb')
response = reader.get(ip)  # 返回字典
```

**错误用法**:
```python
import geoip2.database

reader = geoip2.database.Reader('db/ipinfo_lite.mmdb')
response = reader.city(ip)  # ❌ 不兼容IPinfo格式
```

#### 4. 日志文件过多

**问题**: 每次重启创建新日志文件，导致碎片化

**解决**: 已实施统一日志系统，自动轮转和压缩

#### 5. 城市名称显示英文

**问题**: 城市名称显示 "Shijiazhuang" 而非 "石家庄"

**解决**: 已实现 `city_mapping.py` 包含200+城市映射

## API文档

### 批量DNS查询

**端点**: `POST /api/batch-query`

**请求头**:
```
Content-Type: application/json
```

**请求体**:
```json
{
  "domains": ["baidu.com", "google.com"],
  "dns_servers": ["8.8.8.8", "114.114.114.114"]
}
```

**响应** (200 OK):
```json
[
  {
    "domain": "baidu.com",
    "ip": "110.242.74.102",
    "dns": "8.8.8.8",
    "city": "石家庄",
    "country": "中国",
    "source": "local:ipinfo"
  },
  {
    "domain": "baidu.com",
    "ip": "111.63.65.103",
    "dns": "8.8.8.8",
    "city": "天津",
    "country": "中国",
    "source": "local:geolite2"
  }
]
```

**字段说明**:
- `source`: 数据来源
  - `local:ipinfo` - IPinfo MMDB
  - `local:geolite2` - GeoLite2 MMDB
  - `api` - IPinfo API (降级)
  - `cache` - 缓存命中

**错误响应** (400 Bad Request):
```json
{
  "error": "请求格式错误"
}
```

**速率限制**: 200请求/分钟

### 查询历史

**文件位置**: `log/query_history.json`

**格式**:

[
  {
