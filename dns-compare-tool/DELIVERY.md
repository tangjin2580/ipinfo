## 🚀 快速使用指南


### 基本操作流程

1. **输入域名**
   - 在左侧文本框输入域名（每行一个）
   - 或点击快捷按钮添加常用域名

2. **选择DNS**
   - 勾选需要对比的DNS服务器
   - 可添加自定义DNS服务器

3. **开始解析**
   - 点击"开始解析"按钮
   - 等待查询完成（显示加载动画）

4. **查看结果**
   - 表格展示解析结果
   - IP不一致的项会高亮显示
   - 可导出为CSV或JSON

5. **查看历史**
   - 底部显示最近10条查询历史
   - 点击历史记录可快速重新查询

## 🔧 API配置说明

### 修改API地址

编辑 `index.html` 文件，修改第556行：

```javascript
data() {
    return {
        apiBaseUrl: 'http://localhost:8080',  // 👈 修改这里
        // ...
    }
}
```

将 `http://localhost:8080` 替换为您的实际API地址。

### API接口要求

后端API需要实现以下3个接口：

#### 1. 批量查询接口
```
POST /api/batch-query
Content-Type: application/json

请求体：
{
  "domains": ["example.com"],
  "dns_servers": ["8.8.8.8"]
}

响应：
[
  {
    "domain": "example.com",
    "ip": "93.184.216.34",
    "dns": "8.8.8.8",
    "country": "United States",
    "city": "Norwell",
    "isp": "EdgeCast Networks",
    "resolve_time": 45
  }
]
```

#### 2. 历史记录接口
```
GET /api/history?limit=10

响应：
[
  {
    "domain": "example.com",
    "ip": "93.184.216.34",
    "dns": "8.8.8.8",
    "country": "United States",
    "city": "Norwell",
    "isp": "EdgeCast Networks",
    "timestamp": "2026-01-26T14:08:57Z"
  }
]
```

#### 3. 清除缓存接口
```
POST /api/clear-cache

响应：
{
  "success": true,
  "message": "Cache cleared successfully"
}
```

### CORS配置

确保后端API允许跨域请求，需要设置以下响应头：

```
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type
```

## 🐛 已知限制

1. **API依赖**
   - 需要配置后端API才能进行真实DNS查询
   - 演示模式使用模拟数据

2. **浏览器存储**
   - 历史记录存储在LocalStorage
   - 清除浏览器数据会丢失历史记录

3. **查询限制**
   - 单次查询建议不超过10个域名
   - 大量查询可能导致超时
